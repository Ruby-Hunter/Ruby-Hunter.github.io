PROJECT 04 / EMBEDDED & DIGITAL LOGIC

Data verification & validation

Verifying weather data before sending it to a remote server.

AREA
Embedded & digital logic
PLATFORM
ESP32 / FPGA
FOCUS
CRC / Packetization
COURSE
Class project
01 / Overview 02 / System outline 03 / Components

01 / OVERVIEW

The project

An ESP32 and FPGA receive weather data from a peripheral device. The system computes a CRC checksum, packetizes the data, and sends it to a remote server for display.

02 / SYSTEM OUTLINE

How it connects

Weather peripheral→ESP32 + FPGA→CRC + Packetization→Remote server

03 / COMPONENTS

Hardware & software

  • Peripheral device supplying weather data.
  • ESP32 and FPGA for the data verification system.
  • CRC checksum computation and data packetization.
  • Remote server for displaying the transmitted data.
